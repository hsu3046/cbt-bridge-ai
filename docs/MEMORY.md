## 重要な決定事項

| 項目 | 決定 | 理由 |
|------|------|------|
| 分割ビュー方式 | 同URL新ウインドウ + 全文翻訳 | 同レイアウトで比較可能 |
| コスト制御 | 10段落チャンク + 確認ダイアログ | API料金暴走防止 |
| モデル選択 | 3段階ハイブリッド | コスト対品質最適化 |
| ランタイム依存 | ゼロ | セキュリティ + バンドルサイズ |
| 翻訳表示 | インライン置換 + クリックトグル | 最もシンプル |

## 既知のバグ / 注意点

### BUG-001: macOS での分割ビューウインドウリサイズ
- **症状:** 元ウインドウが50%にリサイズされない
- **状態:** 調査中（デバッグログ追加済み）
- **暫定対策:** `chrome.windows.update` の前に `state: 'normal'` 設定

### BUG-002: 拡張リロード後のContent Script不整合
- **症状:** `net::ERR_FILE_NOT_FOUND` (旧ビルドのJSファイル参照)
- **対策:** 拡張を完全に削除 → 再読み込み。単純なリロードでは不十分な場合あり。

### BUG-003: Cookie バナーの大量翻訳
- **症状:** 407段落中ほとんどがCookie関連テキスト → 本文に到達しない
- **対策済:** 本文検出アルゴリズム + 除外フィルター + チャンク翻訳

## 繰り返しパターン

1. **CRXJS キャッシュ問題** — `dist/` を削除して `npm run build` でクリーンビルドが安全
2. **Service Worker の `chrome.windows.getCurrent()`** — SW コンテキストでは不安定。`sourceTab.windowId` → `chrome.windows.get()` を使用
3. **`return true` in onMessage listener** — `sendResponse` を使う場合、リスナーから `return true` が必須
